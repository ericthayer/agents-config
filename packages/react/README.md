# @agents-config/react

React-family guidance for AI coding assistants, including the existing Next.js,
Remix, and legacy Astro configuration options.

```sh
npm install --save-dev @agents-config/react
npx agents-init
npx agents-analyze
```

Use `--stack react` when multiple presets are installed. Optional MUI, Tailwind,
Supabase, Gemini, Storybook, and React Three Fiber guidance follows project
dependencies and configuration flags.

The unscoped `agents-config` package remains a compatible React entry point.
Root repository documents are the editable source; `npm run prepare:packages`
stages them into this package before packing.

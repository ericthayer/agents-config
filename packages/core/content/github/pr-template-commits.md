# Pull request from commits

Read the repository's PR template, current branch diff, and commit history.
Describe the consumer-facing change, not merely the files touched.

## Summary

Explain the problem and the resulting behavior.

## Changes

List the meaningful changes and any deliberate scope exclusions.

## Validation

Record the commands actually run and their outcomes. State missing coverage or
environment limitations instead of claiming verification that did not happen.

## Compatibility

Describe changed contracts, configuration, migration steps, and rollback needs.
State explicitly when no consumer action is required.

## References

Link related issues and decisions. Do not invent issue numbers or approvals.
